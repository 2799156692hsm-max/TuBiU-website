# 《独一无二的我》互动 3D 绘本

这是一个无外部依赖的静态 HTML 版本，直接打开根目录 `index.html` 即可使用；`dist` 目录是完全相同的线上发布版本。

## 交互

- 点击封面打开绘本；右上角按钮可合上绘本。
- 读到最后一页后继续向右，或在末页合上绘本，即可看到完整封底。
- 在书本上向左或向右拖拽翻页。
- 可使用两侧翻页按钮，也可使用键盘左右方向键。
- 声音按钮控制轻柔风声、翻页声和风铃提示音。
- 每张内页图片完整横跨一整个摊开跨页，中缝仅叠加装订阴影，不裁切原图。

## 部署

将本目录整体上传到任意静态网站托管服务即可。入口文件为 `index.html`。
